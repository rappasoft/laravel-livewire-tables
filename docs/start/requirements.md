---
title: Requirements
weight: 1
---

The following are required to use this package regardless of what theme you choose:

- PHP 8.1+ (8.3+ if you are on Laravel 13)
- [Laravel 10.x, 11.x, 12.x or 13.x](https://laravel.com)
- [Laravel Livewire 3.x](https://livewire.laravel.com)

Laravel 10 and 11 compatibility is retained, but these releases are outside security support and have unresolved upstream advisories. Use Laravel 12.69+ or 13.30+ in production. Known framework advisories are allowlisted only in the legacy CI jobs; the package does not disable Composer security checks for applications.
